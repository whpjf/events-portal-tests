# Задание 3. Тестирование формы регистрации

Форма: `http://localhost:8103/register`, пять полей (логин, почта, телефон, пароль, повтор пароля). Тесты в `tests/test_forms.py`, 32 проверки. Каждая строка таблицы это один тест с тем же номером. Данные взяты по классам эквивалентности и граничным значениям: для каждого поля допустимое значение, значения на границе и недопустимые значения разных видов. Остальные поля в каждой проверке заполнены верно.

Ожидание «принят» значит ответ 303 (переход после регистрации), «отклонён» значит ответ 422 и сообщение под полем.

«До» это версия портала `996a8f7`, «после» это исправленная.

## Итог

Из 32 проверок до исправлений не прошли 6 (F-11, F-12, F-15, F-21, F-22, F-30), после исправлений проходят все. Это ошибки BR-04 и четыре новые: перевод строки в конце проходил проверку (в регулярном выражении `$` пропускает его), пароль из пробелов, почта с зоной из одной буквы, телефон из арабских цифр (`\d` в Python считает цифрой любой знак категории «цифра»). Подробные описания и исправления в `Практика 16` репозитория портала.
