# Тестирование портала «Конференции.РФ»

Тестовая документация и автотесты к МДК.05.03 «Тестирование информационных систем». Тестируется учебный портал из репозитория [events-portal](https://github.com/whpjf/events-portal) (Python, FastAPI).

## Задания

| Папка | Что внутри |
|---|---|
| `Задание 1. Чек-лист, тест-кейсы, баг-репорты` | чек-лист из 16 пунктов, 5 тест-кейсов, 6 баг-репортов со скриншотами |
| `Задание 2. Анализ запросов в DevTools` | разбор POST входа на портале и GET страницы Википедии |
| `Задание 3. Тестирование форм` | форма регистрации: 32 проверки по классам эквивалентности и граничным значениям |
| `Задание 4. Автотест входа на Selenium` | Page Object, явные ожидания, скриншот при падении |
| `Задание 5. Смоук-тесты и CI` | 5 смоук-тестов и запуск в GitHub Actions |
| `Отчет МДК.05.03.docx` | отчёт по всем заданиям |

## Как запустить

Нужны Python 3.12 и Chrome. Репозиторий портала должен лежать рядом: `events-portal` и `events-portal-tests` в одной папке (или путь в переменной `PORTAL_DIR`).

```
python -m venv .venv
.venv\Scripts\pip install -r ..\events-portal\portal\requirements.txt -r requirements.txt
.venv\Scripts\python -m pytest                 все тесты
.venv\Scripts\python -m pytest -m smoke        только смоук
```
Тесты сами создают базу во временной папке, применяют миграции, заливают учебные данные и запускают портал на порту 8103 (`PORTAL_PORT` меняет порт). Перед каждым тестом данные возвращаются к исходным. Браузер запускается без окна, чтобы показать окно: `set HEADLESS=0`.

## Структура

```
conftest.py        запуск портала, браузер, скриншот при падении
pages/             Page Object: base_page, login_page, events_page, apply_page
tests/             test_smoke, test_login, test_forms, test_errors, test_demo_failure

```
